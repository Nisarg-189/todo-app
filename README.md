# To-Do List CLI App

A simple and clean command-line To-Do List application built with Python.  
It supports adding tasks, viewing tasks, marking them as completed, and deleting them.  
All tasks are saved in a JSON file so your to-do list stays even after exiting the program.

## Features
- Add new tasks
- View all tasks with status
- Mark tasks as completed
- Delete tasks
- Persistent storage using JSON
- Clean and modular code structure
